# Student Portfolio Website

## Run it
1. Open the `student-portfolio` folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Replace `Your Name`, sample text and example journal entries with your own content.

## Images
Put your own images in `assets/images/` using these filenames:
- profile.jpg
- hobby-1.jpg
- hobby-2.jpg
- hobby-3.jpg
- project-1.jpg

You can also change the image paths in the HTML files. Use images you own or have permission to use. Avoid uploading private or identifying photos.

## Journal
Edit the `journalPosts` array near the top of `js/journal.js`. Add a new object with a unique `id`, title, date (`YYYY-MM-DD`), category (`School`, `Hobbies`, or `Life`), snippet, content and starting likes.

## Important limitations
- Likes and comments are saved only in the current browser/device using localStorage. They are not shared with other visitors.
- The contact form is a local demo. It does not send email or upload messages to a server.
- Do not publish home addresses, phone numbers, school schedules, passwords or other private details.
