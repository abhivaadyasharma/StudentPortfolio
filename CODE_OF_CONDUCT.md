# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone who contributes to or interacts with this project.

Everyone should feel safe sharing ideas, reporting issues, suggesting improvements, and contributing to the project.

## Our Standards

Examples of positive behaviour include:

- Being respectful and considerate towards others.
- Using friendly and inclusive language.
- Accepting constructive feedback gracefully.
- Respecting different opinions and perspectives.
- Giving credit to original creators.
- Helping maintain a positive learning environment.

Examples of unacceptable behaviour include:

- Harassment, bullying, or discrimination.
- Insulting or disrespectful comments.
- Sharing someone else's private information without permission.
- Plagiarism or claiming another person's work as your own.
- Deliberately disrupting discussions or contributions.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues and discussions.
- Pull requests.
- Project-related communications.
- Any other space where contributors represent this project.

## Reporting Issues

If you experience or witness unacceptable behaviour, report it by opening a GitHub issue or contacting the repository owner privately.

All concerns will be reviewed respectfully and handled appropriately.

## Enforcement

Project maintainers have the right to review reports and take appropriate action, including:

- Removing inappropriate comments or content.
- Rejecting contributions that violate these standards.
- Restricting participation in project discussions when necessary.

## Attribution

## Final Note

This project is intended to encourage creativity, learning, collaboration, and responsible web development.

Let's keep it respectful, constructive, and enjoyable for everyone!
